## 🚀 About Me

Sou desenvolvedor web e estudante de Engenharia de Software, apaixonado por tecnologia, desenvolvimento de produtos digitais e criação de soluções que realmente resolvem problemas.

Atualmente trabalho no desenvolvimento de aplicações web completas — do frontend ao backend —, com experiência em bancos de dados, autenticação, APIs, pagamentos, integrações e deploy. Também venho explorando cada vez mais JavaScript, Java, automações e ferramentas de IA para acelerar o desenvolvimento e criar produtos mais inteligentes.

Além de programar, trabalho com produtos digitais e negócios online, o que me deu uma visão que vai além do código: penso em produto, experiência do usuário, vendas, automação e escalabilidade.

Hoje meu objetivo é evoluir constantemente como desenvolvedor, construir projetos cada vez mais profissionais e transformar ideias em produtos funcionais — do primeiro protótipo até uma aplicação pronta para usuários reais.
